# Symparanekromenoi

Some DevOps project for managing servers, projects, container deployments and observing the infrastructure.

## Stack

* PHP 8.5, Laravel 13
* GraphQL/Lighthouse 
* Vue 3 with Pinia 
* PostgreSQL 18 
* Redis/Horizon 
* Laravel Reverb

## Architecture 

A modular Laravel monolith with a Vue frontend. [ [architecture.md](docs/architecture.md) ]
